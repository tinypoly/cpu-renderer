@tinypoly/cpu-renderer
GitHub

Three.js scenes, rendered on the CPU

A software renderer for Three.js scenes. It takes an ordinary THREE.Scene and renders it on the CPU across a pool of Web Workers, bucket by bucket, into a 2D canvas. It never creates a WebGL context.

It powers the render mode of the Tinypoly editor.

Made with by Danilo Gadelha
